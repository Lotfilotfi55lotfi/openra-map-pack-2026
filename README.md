## 🔧 Troubleshooting Tips

### Maps not showing up in OpenRA?

Make sure you copied the `.oramap` files directly into the `maps` folder. Do not put them in subfolders. Also, restart OpenRA completely after copying.

### Game crashes when loading a map?

Some maps may require more memory. Close other programs before playing. If the issue persists, try a different map.

### Can't find the `maps` folder?

Press `Windows Key + R`, type `%appdata%\OpenRA`, and press Enter. If there's no `maps` folder, right-click in the window, select "New Folder," and name it `maps`.
