## FAQ

**How do I install the maps?**  
Run the included installer or copy map files to %APPDATA%\OpenRA\Maps\. The installer handles this.

**Do these maps work in online multiplayer?**  
Yes — all maps are compatible with OpenRA's online multiplayer.
